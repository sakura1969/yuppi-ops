YUPPI OPS iPhone/Android 共有用

GitHub PagesなどHTTPSのWebホスティングに、このフォルダ内のファイルをすべて同じ場所へアップロードしてください。index.htmlだけをLINEで送ってもPWAにはなりません。公開されたURLをLINEで共有します。

iPhone: SafariでURLを開き、共有→ホーム画面に追加。Android: ChromeでURLを開き、メニュー→ホーム画面に追加/アプリをインストール。

各端末のlocalStorageに個別保存されます。ブラウザのデータ削除で消える場合があります。OCRにはインターネット接続が必要で、iPhone Safariでの動作確認は未実施です。
